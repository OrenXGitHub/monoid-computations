# Computational supplement to *On a conjecture of Fiedorowicz*

This repository contains reproducible Python calculations accompanying Oren
Ben-Bassat's paper *On a conjecture of Fiedorowicz*. The paper proves that
every finite simply connected CW complex is homotopy equivalent to the
classifying space of a finite aperiodic monoid. The programs here construct
the explicit monoids used in the examples and check their finite algebraic and
homological data.

## The construction implemented here

Let `L` be a finite monoid, let `Y` be a finite reduced simplicial set of
dimension `n`, and let

```text
f: Y -> N(L)
```

be a simplicial map to the nerve of `L`. The paper defines a finite monoid

```text
M(Y,f) = End_Delta([n])^op  disjoint-union
         (Y_n x L x {0,...,n})
```

and proves

```text
B M(Y,f)  ~=  Cof(|f|: |Y| -> BL).
```

The function `cofiber_monoid` in `cofiber_monoids.py` implements this
construction. In the program, `Y` is presented as the simplicial subset of
the nerve of an auxiliary monoid `H` generated by a finite list of
`n`-simplices, and `f` is induced by a homomorphism `H -> L`. The function:

1. closes the given simplices under all simplicial operators;
2. enumerates the elements of `M(Y,f)`;
3. constructs its complete multiplication table; and
4. returns the table, readable element labels, and the list of `n`-simplices
   of `Y`.

The script then checks the identity and associativity laws and, for selected
examples, computes `H^*(BM; F_2)` and Yoneda products from an explicit
projective resolution of the trivial `F_2[M]`-module.

## The 1795-element model of `CP^2`

The main example starts with the five-element aperiodic monoid `L0` whose
classifying space is `S^2`. An integral normalized 2-cocycle `u` defines the
central extension

```text
P = L0 x_u Z.
```

The constant `HOPF_SPHERE` is the promised finite list: it contains twelve
triples of elements of `P`, regarded as nondegenerate 3-simplices of `N(P)`.
They generate a finite simplicial subset `Y` with 88 simplices in degree 3
after degenerate simplices are included. Projection `P -> L0` induces the map
`f: Y -> N(L0)`.

The function `hopf_sphere_check` verifies this input using exact arithmetic:

1. it constructs the normalized integral boundary matrices of `Y`;
2. unit minors show that `H_1(Y) = H_2(Y) = 0` and `H_3(Y) = Z`;
3. the triangle relations reduce all seven edge generators to the identity,
   proving `pi_1(Y) = 0`; and
4. an integral cochain calculation evaluates the Hopf invariant of `|f|` on
   an oriented fundamental cycle and obtains `1`.

Thus `|Y| ~= S^3` and `|f|` is a Hopf map. The construction produces

```text
|M(Y,f)| = 35 + 4 * 5 * 88 = 1795,
```

and the theorem in the paper gives `BM(Y,f) ~= CP^2`.

The subsequent calculation of the mod-2 cohomology ring through degree 9 is
an independent consistency check: it finds Betti numbers

```text
1, 0, 1, 0, 1, 0, 0, 0, 0, 0
```

and a nonzero square of the degree-two class. This finite-range cohomology
calculation is not being used as a substitute for the mapping-cone theorem.

## Files

- `cofiber_monoids.py` implements `M(Y,f)`, verifies the explicit simplicial
  Hopf sphere, and computes the stated mod-2 cohomology rings. Its largest
  example is the 1795-element monoid modeling `CP^2`.
- `annulus_cp2.py` constructs a separate 122-element annulus monoid and
  computes its cohomology rings over `F_2`, `F_3`, `F_5`, and `F_7`.
- `check_cp2_corners.py` checks left- and right-collapsing idempotent criteria
  and proper idempotent corners of the 122- and 1795-element models. It emits
  a machine-readable JSON report.
- `aperiodic_minimality_census.py` reads the GAP Smallsemi census through
  order six and checks the lower bound for a monoid modeling
  `S^2 wedge S^2`.

The programs provide finite, reproducible checks of examples and lower
bounds. The general mapping-cone theorem is proved in the paper.

## Requirements

- Python 3.10 or newer
- NumPy 1.24 or newer
- For `aperiodic_minimality_census.py` only: the data files from the GAP
  Smallsemi package

Create an isolated environment from this directory:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

On Windows, replace the activation command by:

```powershell
.venv\Scripts\activate
```

## Run the checks

The cohomology and corner calculations are substantially heavier than the
initial construction and exact Hopf-sphere verification.

### Mapping-cone examples and the 1795-element `CP^2` model

```bash
python cofiber_monoids.py
```

The final report should give oriented Hopf invariant `1`, the mod-2 Betti
numbers displayed above, and a nonzero square in degree four.

### The 122-element annulus model

```bash
python annulus_cp2.py
```

The first line should report `|M| = 122` and confirm that multiplication is
associative and unital. For each of the four primes, the reported Betti
numbers begin `1, 0, 1, 0, 1`, with a nonzero product from degree two to
degree four.

### Idempotent-corner checks

```bash
python check_cp2_corners.py > corner-report.json
```

A successful run exits without an assertion failure. The JSON report records
that neither explicit `CP^2` model has a left- or right-collapsing proper
idempotent and that the tested proper corners do not retain the `CP^2`
cohomology signature.

### Small-monoid census

Download and unpack the official GAP Smallsemi package from
<https://gap-packages.github.io/smallsemi/>. The required compressed files
are `data2.gl.gz` through `data6.gl.gz`, normally found in
`smallsemi-*/data/data2to7/`. Pass that directory to the script:

```bash
python aperiodic_minimality_census.py \
  /path/to/smallsemi/data/data2to7 \
  --max-order 6
```

The census should report, for orders one through six, respectively:

```text
monoids:                    1, 2, 6, 27, 156, 1373
group-completion-trivial:   1, 1, 4, 19, 127, 1165
maximum dim H_2(-; F_2):    0, 0, 0, 0, 1, 1
```

Thus none of these monoids has the second homology required by
`S^2 wedge S^2`.
